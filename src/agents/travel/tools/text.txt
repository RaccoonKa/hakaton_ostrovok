Спецификация инструментов (Tools Contract)
1. Тул: search_destinations (Поиск городов и направлений)
Назначение: Разрешение названий городов из естественного языка в нормализованные сущности и IATA-коды аэропортов для Aviasales, а также получение идентификаторов локаций для Яндекс Путешествий.

Входные данные (SearchDestinationsInput):

query: str — поисковая фраза пользователя (например, "Сочи", "Питер", "Калининград", "Дубай").

Выходные данные (DestinationResult):

city_name: str — официальное название города (например, "Санкт-Петербург").

country_name: str — страна (например, "Россия").

iata_code: str — трёхбуквенный международный код аэропорта/города (например, "LED").

yandex_geo_id: str | None — идентификатор локации/региона для Яндекс Путешествий.

is_popular: bool — флаг туристической популярности.

2. Тул: search_flights (Поиск авиабилетов через Aviasales / Travelpayouts)
Назначение: Запрос билетов на самолет по маршруту туда (или туда-обратно) с фильтрацией по датам и пересадкам.

Входные данные (SearchFlightsInput):

origin_iata: str — IATA-код города отправления (например, "MOW").

destination_iata: str — IATA-код города прибытия (например, "AER").

departure_date: str — дата вылета в формате YYYY-MM-DD.

return_date: str | None — дата возвращения YYYY-MM-DD (если перелёт в обе стороны).

direct_only: bool — искать только прямые рейсы (по умолчанию False).

passengers_count: int — количество пассажиров (по умолчанию 1).

Выходные данные (FlightOffersResponse):

offers: list[FlightOffer], где каждый билет содержит:

offer_id: str — уникальный ID предложения.

airline_name: str — название авиакомпании (например, "Аэрофлот").

flight_number: str — номер рейса.

departure_time: str — время вылета (ISO-формат или HH:MM).

arrival_time: str — время прилета.

duration_minutes: int — общее время в пути.

transfers_count: int — количество пересадок.

price: float — стоимость билета на человека в рублях.

booking_url: str — прямая ссылка на покупку/бронирование.

3. Тул: search_hotels (Поиск отелей через Яндекс Путешествия)
Назначение: Поиск вариантов проживания (гостиницы, апартаменты) на выбранные даты с фильтрацией по бюджету и уровню комфорта.

Входные данные (SearchHotelsInput):

location: str — город или идентификатор локации (yandex_geo_id или название).

check_in_date: str — дата заезда YYYY-MM-DD.

check_out_date: str — дата выезда YYYY-MM-DD.

guests_count: int — количество гостей (по умолчанию 1).

max_price_per_night: float | None — предельная цена за одну ночь в рублях.

min_rating: float | None — минимальный рейтинг отеля (например, 7.5 или 8.0).

stars: list[int] | None — фильтр по звёздам (например, [3, 4]).

Выходные данные (HotelOffersResponse):

hotels: list[HotelOffer], где каждый отель содержит:

hotel_id: str — идентификатор отеля в базе Яндекса.

name: str — название отеля (например, "Гранд Отель Поляна").

address: str — точный адрес или район.

stars: int — категория звёзд (от 0 до 5).

rating: float — пользовательский рейтинг (например, 8.9).

price_per_night: float — стоимость за одну ночь в рублях.

total_price: float — суммарная стоимость проживания за весь период.

photo_urls: list[str] — ссылки на фотографии (для карточек на фронтенде).

booking_url: str — ссылка на бронирование на Яндекс Путешествиях.

4. Тул: package_travel_options (Компоновка вариантов и подсчёт бюджета)
Назначение: Связывание конкретного авиабилета и отеля в готовый «тур-пакет» с расчетом итогового бюджета поездки на всех участников.

Входные данные (PackageOptionsInput):

flight_offer_id: str — ID выбранного перелета.

hotel_id: str — ID выбранного отеля.

flight_price: float — стоимость билета.

hotel_total_price: float — стоимость проживания за весь период.

travelers_count: int — количество путешественников.

Выходные данные (TravelPackageResult):

package_id: str — UUID скомпонованного варианта.

flights_total: float — общая сумма за авиабилеты на всех человек (flight_price * travelers_count).

hotel_total: float — общая сумма за проживание.

grand_total: float — полная стоимость поездки (билеты + отель).

is_within_budget: bool — укладывается ли пакет в заявленный лимит пользователя (если лимит передавался).

summary_text: str — краткое резюме пакета для вставки в финальный ответ агента.
