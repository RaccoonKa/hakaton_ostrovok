Dockerfile.app — обычно собирает клиентский интерфейс (тестовый UI на Streamlit). Если вы им не пользуетесь, он тоже лишний, но пока можно не трогать.

Dockerfile.service — собирает основной бэкенд на FastAPI с вашим агентом. Его оставьте, он пригодится бэкендерам для деплоя на сервер перед защитой.
